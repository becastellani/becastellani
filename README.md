### 👋 About me

I'm a **Software Engineer** from Brazil 🇧🇷 with 3+ years building critical systems in **finance** and **ERP**. Most of my work is backend: APIs, queues, caching, and getting legacy code back into shape.

- 🏦 At **Sicredi** I work on **CAS Co-creation** (business account opening) with **Java 21, Kafka, Redis, MongoDB and Kubernetes**. It runs in **100 cooperatives** and serves **10M+ members**. I also maintain the cooperative's PHP system for credit, billing and debt negotiation, and write Python/Pandas ETLs for financial reconciliation.
- ⚡ At **Alow** I modernized a legacy telecom ERP in **PHP (Laravel/Symfony)**: **30% faster APIs** with Redis, async processing on **RabbitMQ**, and **~20h/week** of manual work removed with Puppeteer automations.
- 🤖 I'm building **VeraQA**, an LLM agent with **Human-in-the-Loop** validation for automated REST API testing.
- 🎓 Software Engineering (graduating 2026) · **Postgrad in AI**, focused on Intelligent Systems (in progress)
- 🌎 Portuguese (native) · English (B2)
